# Шпаргалка команды — HydroWatch Amur

## Знают все пятеро

- Что делаем: по паре снимков «до» / «пик» → вода на две даты + зона нового затопления + площади.
- Данные: 11 пар, 5 районов Амурской области, Sentinel-1 (SAR) + Sentinel-2 (оптика) + AUX.
- Метрика: 0.45 flood + 0.25 peak + 0.15 pre + 0.15 межень. **Score на платформе 0.768.**
- Модель: сиамская мультимодальная U-Net, два ResNet-18 (SAR / оптика), три головы.
- Честная валидация: Зея-2021 отложена — q_flood 0.53, q_peak 0.57, q_pre 1.0.
- Сервис: `docker compose up` → карта (до / пик / прирост / убыль, шторка), отчёт, GeoJSON/GeoTIFF/CSV/JSON, REST API.
- Ограничения: нет угла падения; воду под кронами не видим; на широких поймах переоцениваем.

## Спикер 1 — капитан (слайды 1–3)

- Затопление = 0.02–2 % сцены (дисбаланс). Оптики нет у 5 из 11 пар.
- «До» → «пик» ≈ 6 недель; SAR–оптика разнесены до 5 суток.
- HAND: медиана 0.5 м у воды vs 3.7 м у фона.
- Зачем: решения ЦУКС/ЦГМС об эвакуации и ущербе — в часах, не неделях.

## Спикер 2 — ML (слайды 4–5)

- Порог Оцу + разность масок ломается: рябь/радиотени (SAR), мутная вода/тени (оптика); ошибки независимы → сливать признаки.
- SAR-энкодер с нуля, оптика — SSL4EO; temporal-признаки pre / peak / Δ на каждом масштабе; AUX = HAND, уклон, GSW, WorldCover; флаг оптики.
- Modality dropout 50 % — без оптики работает штатно.
- Loss: focal Tversky + Dice/BCE + штраф за площадь + логика (flood ⊂ peak, flood ∩ pre = ∅).
- Пороги 0.95 / 0.78 / 0.95; окна 384, stride 256.

## Спикер 3 — эксперименты и эталон (слайды 6–7)

- Self-check 0.758: Q_flood 0.70, Q_peak 0.77, Q_pre 0.68, Spec 1.0. Платформа 0.768.
- С нуля 0.614 против fine-tune 0.489 → 0.449 (val loss — меньше лучше).
- Эталон: у 5 из 11 пар нет постоянной воды в масках (Константиновка-2021: 30 га «до» при 5436 га реки).
- Зея: flood в JSON 2179 га vs маска 2484 га (+14 %). flood ≠ peak−pre−perm: до 1156 га.
- Поярково: орбита 105 покрывала 0.3 % района → переключили на орбиту 32.

## Спикер 4 — продукт (слайды 8–9)

- Свободный (Зея-2021): «до» 3 985 га, пик 6 801 га, новое затопление 3 211 га, убыль 640 га, зеркало +71 %.
- Вход: полигон / bbox + даты (пара подбирается с допуском ±20 дней). Ответ ≈ 1 с.
- API: POST /api/analyze, GET …/report.json|.csv, …/vectors/{layer}.geojson, …/mask.tif, POST /api/observations, Swagger /docs.
- Обновление: сцена S1 → predict 10–20 с на GPU → пересчёт только разности.
- Ресурсы: инференс 2–3 ГБ VRAM; сервис < 1 ГБ RAM; uv.lock, seed 2026, SHA-256, 22 теста.

## Спикер 5 — финал и модератор (слайд 10)

- Ограничения: угол падения, затопленная растительность, широкие поймы (Поярково).
- Развитие: временной ряд S1, выборка 2013/2022, слой double-bounce, агрегация по бассейнам.
- На вопросах: повторить вопрос одной фразой → передать нужному спикеру. Отвечает один.
- Не знаем — говорим «не проверяли, проверили бы так…». С жюри не спорим.
